Blog Application (MERN-style with PostgreSQL)

A full-stack Blog Application built using React (Vite) + Tailwind CSS on the frontend and Express + PostgreSQL (Prisma ORM) on the backend.
Users can sign up, sign in, and perform full CRUD operations on their own blog posts using JWT authentication.

🚀 Features
Authentication

User Signup and Signin

JWT-based authentication

Protected routes using middleware

Blog Management

Create a blog post

View all posts created by the logged-in user

Update a post (only by the author)

Delete a post (only by the author)

Frontend Pages

Landing Page

Signup Page

Signin Page

Dashboard (view & manage blogs)

🛠 Tech Stack
Frontend

React (Vite)

Tailwind CSS

Fetch / Axios for API calls

Backend

Node.js

Express.js

PostgreSQL

Prisma ORM

JSON Web Token (JWT)

CORS
